# Raio-X SUSEP da Associação

Ferramenta gratuita para associações de proteção veicular verem se estão prontas para a regra da SUSEP (Lei Complementar 213/2025 e Resolução CNSP 491/2026): sinistralidade, boleto certo por tipo de veículo, reserva, simulações e plano de 18 meses.

É uma página só (`index.html`), sem servidor. Os dados preenchidos ficam apenas no navegador de quem usa.

Esta ferramenta orienta e não substitui advogado, contador ou atuário.
